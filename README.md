## ⚡ Tech Stack

- **Framework**: React 18 + Vite

- **3D & Motion**: Custom 3D perspective spatial transforms & dynamic specular lighting
- **Typography**: Bebas Neue, Caveat, Space Grotesk, Inter

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/Ayushukla7/AYUSH-UI.git

# Navigate to project directory
cd AYUSH-UI

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
